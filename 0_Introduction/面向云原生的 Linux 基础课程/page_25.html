网络接口管理

查看和管理网络接口的关键命令

$ ip addr show

显示所有网络接口详细信息

$ ip link set eth0 up

启用指定网络接口

$ ifconfig

传统网络接口配置工具

$ ip addr add 192.168.1.10/24 dev eth0

为接口添加IP地址

网络连通性测试

验证网络连接和诊断问题的工具

$ ping -c 4 192.168.1.1

测试到指定主机的连通性

$ traceroute google.com

显示数据包到目标的路径

$ nslookup example.com

查询域名的DNS记录

$ netstat -tuln

显示所有监听的TCP/UDP端口

网络配置

管理网络路由和配置的命令

$ ip route show

显示路由表

$ ip route add default via 192.168.1.1

添加默认网关

$ hostnamectl set-hostname server1

设置主机名

$ systemctl restart networking

重启网络服务

容器网络基础

掌握这些网络基础对于理解容器网络至关重要。容器技术使用网络命名空间（Network Namespaces）隔离容器网络环境， 通过虚拟以太网接口对（veth pairs）和网桥（bridge）实现容器间通信。Docker和Kubernetes都构建在这些Linux网络基础之上。
