标准系统目录

/etc 系统配置文件目录

存储系统级别的配置文件，是系统的"控制中心"

├── /etc/passwd # 用户账户信息
├── /etc/shadow $ 用户密码哈希
├── /etc/hosts # 主机名解析
└── /etc/systemd/ # 服务配置
/var 变量数据目录

存储经常变化的数据，如日志、缓存、数据库等

├── /var/log/ # 系统日志
├── /var/lib/ # 应用程序状态数据
├── /var/www/ # Web服务器文件
└── /var/cache/ # 应用缓存
/usr 用户程序目录

包含大部分用户程序和数据，系统的"软件仓库"

├── /usr/bin/ # 用户命令
├── /usr/lib/ # 共享库文件
├── /usr/share/ # 共享数据
└── /usr/local/ # 本地安装软件

特殊的虚拟文件系统

/proc 进程和内核信息

提供访问内核数据结构的接口，展示系统和进程信息

├── /proc/cpuinfo # CPU信息
├── /proc/meminfo # 内存使用情况
├── /proc/[pid]/ # 进程信息
└── /proc/sys/ # 内核参数
/sys 系统设备和内核信息

提供设备驱动程序和内核子系统的信息接口

├── /sys/class/ # 设备类别
├── /sys/devices/ # 设备层次结构
├── /sys/module/ # 内核模块
└── /sys/fs/cgroup/ # 控制组
/dev 设备文件目录

包含设备文件，代表系统中的硬件设备

├── /dev/sda # 第一个SATA硬盘
├── /dev/null # 空设备（数据黑洞）
├── /dev/tty # 控制终端
└── /dev/random # 随机数生成器
