文件内容查看命令

cat

显示整个文件内容

cat filename

less

分页浏览文件

less filename

head

查看文件开头

head -n 10 filename

tail

查看文件结尾

tail -n 10 filename

文本编辑器

vim/vi

功能强大但学习曲线陡峭

vim filename

nano

简单易用的编辑器

nano filename

文件搜索

find

强大的文件查找工具

find /path -name "*.txt"

locate

基于数据库的快速搜索

locate filename

文本处理工具

grep

文本搜索工具，用于在文件中查找匹配模式的行

grep "pattern" filename

常用选项：-i（忽略大小写）, -r（递归搜索）

sed

流编辑器，用于文本替换、删除和插入操作

sed 's/old/new/g' filename

示例：替换文本中所有的"old"为"new"

awk

强大的文本处理语言，特别适合处理结构化数据

awk '{print $1}' filename

示例：打印每行的第一个字段

sort / uniq

排序和去重

sort file | uniq

wc

统计行数、字数和字节数

wc -l filename
