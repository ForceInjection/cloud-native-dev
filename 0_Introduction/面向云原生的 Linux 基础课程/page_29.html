Linux 内核特性

  • Namespaces：提供进程、网络、文件系统隔离
  • Cgroups：资源限制和监控
  • OverlayFS：分层文件系统支持
  • Netfilter：网络数据包过滤和NAT
  • Bridge：虚拟网桥实现容器间通信
# 检查内核版本（Docker要求3.10+）
$ uname -r
5.15.0-1035-azure

网络命名空间

独立的网络栈实现，提供容器间的网络隔离和通信

  • 每个容器拥有独立的网络接口和路由表
  • Docker网络模式：bridge、host、none、container
  • veth pair技术连接容器与宿主机网络
# 创建网络命名空间
$ ip netns add container1
$ ip netns list
container1

分层文件系统

Docker镜像由多个只读层叠加而成，容器运行时添加可写层

容器可写层
应用层 (应用程序文件)
配置层 (应用配置)
基础系统层 (Alpine/Ubuntu)

优势：

  • 共享基础层，节省存储空间
  • 快速构建和部署
  • 增量更新和传输

进程隔离机制

容器技术通过PID命名空间实现进程隔离

  • 每个容器有独立的进程空间，PID从1开始
  • 容器内进程对宿主机和其他容器进程不可见
  • 资源限制通过cgroups实现，防止单个容器耗尽系统资源
  • seccomp和capabilities提供安全隔离
# 在新的PID命名空间中运行bash
$ sudo unshare --pid --fork --mount-proc bash
$ ps aux
USER PID %CPU %MEM COMMAND
root 1 0.0 0.0 bash
