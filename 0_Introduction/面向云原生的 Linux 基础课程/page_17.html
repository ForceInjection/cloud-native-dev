进程状态详解

  • 创建（New）: 进程正在被创建，分配资源
  • 就绪（Ready）: 进程已准备好运行，等待 CPU 分配
  • 运行（Running）: 进程正在 CPU 上执行
  • 等待（Waiting）: 进程等待某个事件发生（如 I/O 完成）
  • 终止（Terminated）: 进程执行完毕，释放资源

状态转换条件

  • 创建→就绪: fork() 创建进程，exec() 执行程序
  • 就绪→运行: 调度器选择进程并分配 CPU 时间
  • 运行→就绪: 时间片用完或被更高优先级进程抢占
  • 运行→等待: 等待 I/O 完成或其他资源
  • 等待→就绪: 事件完成或资源可用
  • 运行→终止: 调用 exit() 或收到终止信号
