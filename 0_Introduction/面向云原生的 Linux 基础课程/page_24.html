内存监控 - free

基本用法

free # 显示内存使用情况
free -h # 人类可读格式
free -m # 以MB为单位
free -s 2 # 每2秒更新一次

输出字段说明

total 总内存
used 已使用内存
free 空闲内存
shared 共享内存
buff/cache 缓冲/缓存
available 可用内存

实时监控

watch -n 1 free -h

磁盘空间监控 - df

基本用法

df # 显示文件系统磁盘使用情况
df -h # 人类可读格式
df -T # 显示文件系统类型
df -i # 显示inode使用情况

指定文件系统

df /home
df .

输出字段说明

Filesystem 文件系统
Size 总大小
Used 已使用
Avail 可用空间
Use% 使用百分比
Mounted on 挂载点

查找大文件

df -h | grep -E '(8[0-9]|9[0-9])%'

目录空间监控 - du

基本用法

du # 显示当前目录及子目录大小
du -h # 人类可读格式
du -s # 只显示总计
du -a # 显示所有文件和目录

排序和限制

du -h | sort -hr
du -h --max-depth=1

实用示例

找出最大的目录

du -h /home | sort -hr | head -10

找出大于100MB的目录

du -h /var | awk '$1 ~ /[0-9]+G|[5-9][0-9][0-9]M/ {print}'

监控目录大小变化

watch -n 10 'du -sh /var/log'

排除文件

du -h --exclude="*.log" /var
