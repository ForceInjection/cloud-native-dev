# Linux 入门课程 — 面向云原生

## 课程目标

- 理解 Linux 系统架构和文件系统
- 掌握 Linux 基础操作和命令
- 为后续 Docker/Kubernetes 学习打下坚实基础
- 培养云原生开发环境的使用能力
