SSH基础概念

SSH协议特点

  • 加密传输：所有数据都经过加密
  • 身份验证：支持密码和密钥认证
  • 完整性检查：防止数据被篡改
  • 端口转发：支持隧道功能

连接过程

1 客户端连接服务器
2 服务器发送公钥
3 协商加密算法
4 建立加密通道
5 用户身份验证
6 建立会话
默认端口：22
当前版本：SSH-2（安全可靠）
配置文件：~/.ssh/config

SSH客户端使用

基本连接

ssh username@hostname # 连接到远程主机
ssh username@192.168.1.100 # 使用IP地址连接
ssh -p 2222 username@hostname # 指定端口

调试选项

ssh -v username@hostname # 详细输出
ssh -vv username@hostname # 更详细输出
ssh -vvv username@hostname # 最详细输出

执行远程命令

ssh user@host 'ls -la'
ssh user@host 'cd /var/log && tail -f syslog'
ssh user@host < local_script.sh

连接选项

ssh -o ConnectTimeout=10 user@host # 连接超时
ssh -o StrictHostKeyChecking=no user@host # 跳过主机密钥检查
ssh -C username@hostname # 启用压缩

保持连接

ssh -o ServerAliveInterval=60 user@host # 每60秒发送保活包
ssh -o ServerAliveCountMax=3 user@host # 最多3次保活失败

交互式会话

ssh -t user@host 'top' # 强制分配伪终端
ssh -t user@host 'sudo vim /etc/hosts' # 需要交互的命令

SSH密钥认证

生成密钥对

ssh-keygen -t rsa -b 4096 -C "email@example.com" # RSA密钥（推荐4096位）
ssh-keygen -t ed25519 -C "email@example.com" # ED25519密钥（推荐）
ssh-keygen -t ecdsa -b 521 -C "email@example.com" # ECDSA密钥

查看密钥

ls -la ~/.ssh/ # 查看生成的密钥
cat ~/.ssh/id_rsa.pub # 查看公钥内容
ssh-keygen -lf ~/.ssh/id_rsa.pub # 查看密钥指纹

部署公钥

ssh-copy-id username@hostname # 自动部署公钥（推荐）
ssh-copy-id -i ~/.ssh/my_key.pub user@host # 指定公钥文件
ssh-copy-id -p 2222 username@hostname # 指定端口

SSH Agent管理

eval $(ssh-agent -s) # 启动ssh-agent
ssh-add ~/.ssh/id_rsa # 添加私钥到agent
ssh-add -l # 列出已加载的密钥
ssh-add -D # 删除所有密钥

密钥文件说明

id_rsa - 私钥（保密，不可分享）
id_rsa.pub - 公钥（可以分享）
authorized_keys - 服务器端授权公钥文件
known_hosts - 已知主机指纹文件
