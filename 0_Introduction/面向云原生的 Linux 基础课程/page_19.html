进程监控命令

ps - 进程快照

$ ps aux
# 显示所有进程详细信息
$ ps -ef
# 显示进程层次关系

top - 实时监控

$ top
# 实时显示进程状态
$ htop
# 更友好的进程监控工具

进程控制

kill - 发送信号

$ kill -TERM 1234
# 发送终止信号
$ kill -9 1234
# 强制终止进程

nice/renice - 优先级

$ nice -n 10 ./script.sh
# 以较低优先级运行
$ renice -5 -p 1234
# 调整运行中进程优先级

后台进程操作

后台运行

$ command &
# 在后台启动命令
$ nohup command &
# 免疫挂断信号的后台运行

作业控制

$ jobs
# 查看后台作业
$ fg %1
# 将作业1调至前台
$ bg %1
# 在后台继续作业1

常用进程管理组合命令

ps -ef | grep nginx 查找特定进程
pstree -p 显示进程树和PID
killall nginx 终止所有指定名称的进程
top -c 显示完整命令行
