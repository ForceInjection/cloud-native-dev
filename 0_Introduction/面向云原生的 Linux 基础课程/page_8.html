内核空间 (Kernel Space)

  • 最高权限（Ring 0），可执行任何指令
  • 直接硬件访问，控制CPU、内存、磁盘等
  • 负责进程、内存、文件系统管理
  • 提供系统服务，保障系统安全

用户空间 (User Space)

  • 受限权限（Ring 3），不能执行特权指令
  • 不能直接访问硬件，需通过系统调用
  • 程序间相互隔离，提高系统稳定性
  • 应用程序和系统库在此运行
