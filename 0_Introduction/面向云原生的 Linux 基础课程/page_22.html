权限管理命令

chmod 命令

修改文件或目录的访问权限

chmod 755 file.txt # 数字模式: rwxr-xr-x
chmod u+x,g-w,o=r file.txt # 符号模式
u: 所有者 | g: 用户组 | o: 其他用户 | a: 所有人

chown 和 chgrp 命令

修改文件或目录的所有者和用户组

chown user1 file.txt # 更改所有者
chown user1:group1 file.txt # 同时更改所有者和组
chgrp group1 file.txt # 只更改所属组

特殊权限

SetUID (4000) 执行时具有所有者权限
SetGID (2000) 执行时具有所属组权限
Sticky Bit (1000) 只有所有者才能删除文件
chmod 4755 script.sh # 设置 SetUID
