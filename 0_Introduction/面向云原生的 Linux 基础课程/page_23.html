软件包管理

第 23 页 / 共 32 页

系统更新 

$ sudo apt update                     # 更新软件包索引
$ sudo apt upgrade                    # 升级已安装的软件包
$ sudo apt full-upgrade               # 智能升级（可能会移除部分包）

软件包安装与删除 

$ sudo apt install package_name      # 安装软件包
$ sudo apt remove package_name       # 删除软件包（保留配置）
$ sudo apt purge package_name        # 完全删除软件包及配置
$ sudo apt autoremove                # 清理不需要的依赖包

软件包搜索与信息 

$ apt search keyword                # 搜索软件包
$ apt show package_name              # 显示软件包信息
$ apt list --installed               # 列出已安装的软件包

系统更新 

$ sudo dnf check-update              # 检查可用更新
$ sudo dnf update                    # 更新所有软件包
$ sudo dnf update package_name       # 更新特定包

软件包安装与删除 

$ sudo dnf install package_name      # 安装软件包
$ sudo dnf remove package_name       # 删除软件包
$ sudo dnf autoremove                # 删除孤立依赖
$ sudo dnf groupinstall "Development Tools" # 安装包组

历史和事务管理 

$ dnf history                      # 查看操作历史
$ dnf history info ID                # 查看特定操作详情
$ sudo dnf history undo ID           # 撤销操作

编译环境准备 

$ sudo apt install build-essential     # Ubuntu/Debian
$ sudo dnf groupinstall "Development Tools" # CentOS/RHEL/Fedora
$ sudo apt install autoconf automake libtool pkg-config # 自动构建工具

典型编译安装流程

1. 下载源码

$ wget URL
$ tar -xzf file.tar.gz
$ cd directory

2. 配置

$ ./configure
$ ./configure --prefix=/usr/local
$ ./configure --help

3. 编译

$ make
$ make -j$(nproc)
$ make test

4. 安装

$ sudo make install
$ sudo ldconfig
$ make clean

常用配置选项

  • --prefix=PATH
