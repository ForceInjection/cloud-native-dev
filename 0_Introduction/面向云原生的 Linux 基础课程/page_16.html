进程 (Process)

定义：正在执行的程序实例，是系统资源分配的基本单位

  • 拥有独立的内存空间和系统资源
  • 每个进程有唯一的 PID (Process ID)
  • 完整生命周期：从程序加载到执行结束
进程内存布局
内核空间
系统调用、中断处理
栈 (Stack)
局部变量、函数参数（向下增长）
未使用空间
堆 (Heap)
动态分配内存（向上增长）
数据段 (Data)
全局变量、静态变量
代码段 (Text)
程序指令

线程 (Thread)

定义：进程内的执行单元，是 CPU 调度的基本单位

  • 共享进程的内存空间和资源
  • 创建和切换开销小，便于并发编程
  • 相比进程，线程的创建和销毁更快
