终端模拟器

  • GNOME Terminal (Ubuntu默认)
  • Konsole (KDE桌面环境)
  • iTerm2 (macOS)
  • Windows Terminal
  • Terminator (支持分屏)

Bash Shell特性

  • 命令历史：记录执行的命令
  • 命令补全：Tab键自动补全
  • 别名支持：创建命令别名
  • 作业控制：前后台进程管理
  • 脚本编程：支持复杂脚本逻辑

命令行提示符解读

bash
student@ubuntu:~/Documents$ _
  • student: 当前用户名
  • ubuntu: 主机名
  • ~/Documents: 当前目录 (~表示主目录)
  • $: 普通用户提示符 (root用户为 #)

快捷键和命令历史

光标移动

Ctrl+A 移动到行首
Ctrl+E 移动到行尾
Alt+F 向前一个单词

文本编辑

Ctrl+U 删除至行首
Ctrl+K 删除至行尾
Ctrl+W 删除前一个单词

进程控制

Ctrl+C 终止当前进程
Ctrl+Z 暂停当前进程
Ctrl+D 发送EOF/退出

历史命令

history 查看历史
!! 执行上一条命令
Ctrl+R 搜索历史命令
