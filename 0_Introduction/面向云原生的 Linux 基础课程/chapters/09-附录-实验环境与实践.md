# 附录：实验环境、实践项目与学习路径

## A.1 实验环境

### 推荐配置

- Ubuntu 22.04 LTS 或更新版本
- 虚拟机（VirtualBox/VMware）或云服务器（AWS EC2/Azure VM 免费层）
- 至少 2 GB 内存，20 GB 存储
- 网络连接

### 实验工具

- SSH 客户端（Windows: Windows Terminal + OpenSSH, macOS: 内置 Terminal + iTerm2）
- 文本编辑器（VS Code 或 vim）
- Docker Desktop（容器实验用，可选）

## A.2 实践项目

完成前 8 章后，通过以下项目检验学习效果：

### Web 服务器搭建

- Nginx 安装和配置
- 静态网站部署
- 访问日志分析

### 自动化脚本

- 编写系统监控脚本（CPU/内存/磁盘）
- 编写日志分析脚本（提取错误、统计频率）
- 编写备份脚本（定时打包 + 清理旧备份）

### 容器化部署（进阶）

- 将上述 Web 服务编写 Dockerfile
- 使用 docker-compose 编排 Web + DB 服务

> 完整脚本示例见 `demos/system_monitor.sh`、`demos/log_analyzer.sh`、`demos/auto_deploy.sh`。

## A.3 学习路径建议

1. **基础阶段**（1-2 周）：第 1-3 章——基本命令和文件操作
2. **系统管理阶段**（2-3 周）：第 4-6 章——进程、网络、软件包管理
3. **脚本编程阶段**（1-2 周）：第 7 章——Shell 脚本
4. **云原生预备阶段**（1-2 周）：第 8 章——容器技术基础
5. **实践阶段**：完成 §A.2 的 1-2 个项目
