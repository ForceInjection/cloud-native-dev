标准输入输出错误

0

标准输入 (stdin)

程序从中读取输入的数据流，默认为键盘

1

标准输出 (stdout)

程序正常输出的数据流，默认为终端

2

标准错误 (stderr)

程序错误信息的数据流，默认为终端

重定向操作符

> 覆盖写入文件
>> 追加到文件
2> 错误重定向
< 输入重定向
| 管道

实用示例

输出重定向 

ls > filelist.txt         # 保存文件列表
date >> log.txt           # 追加日期到日志
command 2> error.log     # 错误输出到文件
command &> all.log       # 所有输出到文件

输入重定向 

sort < data.txt          # 从文件读取排序
wc -l < file.txt         # 统计文件行数
cat << EOF               # Here Document
多行文本输入
EOF

管道组合 

ps aux | grep firefox   # 查找进程
ls | wc -l               # 统计文件数
history | tail -10       # 最近10条命令
cat log | tee backup.log # T型管道

高级组合 

command1 && command2     # 成功后执行
command1 || command2     # 失败后执行
command > /dev/null      # 丢弃输出
(cmd1; cmd2) | cmd3     # 子shell组合
