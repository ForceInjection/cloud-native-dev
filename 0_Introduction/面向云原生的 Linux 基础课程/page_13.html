Shell 脚本基础

Shell 脚本优势

  • 自动化重复任务
  • 批量处理文件
  • 系统管理和监控
  • 简化复杂操作
  • 提高工作效率

常用 Shell 类型

bash Bourne Again Shell - 最常用
zsh Z Shell - 功能丰富
fish Friendly Interactive Shell - 用户友好
sh Bourne Shell - 传统 Shell
dash Debian Almquist Shell - 轻量级

脚本创建和执行

创建带有执行权限的脚本文件，使用Shebang定义解释器

# 创建脚本文件
echo '#!/usr/bin/env bash' > script.sh
echo 'echo "Hello World"' >> script.sh

# 添加执行权限
chmod +x script.sh

# 执行脚本
./script.sh
# 或者
bash script.sh

变量定义和使用

定义变量时不加$符号，使用时需要加$符号

# 变量定义（等号两边不能有空格）
name="Linux"
age=25
version="2.0"

# 变量使用
echo "Hello $name"
echo "Age: ${age}"
echo "Version: $version"

条件判断 if-then-else

使用 if 语句进行条件判断和分支控制

# 基本 if 语句
age=18
if [ $age -ge 18 ]; then
    echo "你已经成年了"
fi

# if-else 语句
score=85
if [ $score -ge 90 ]; then
    echo "优秀"
else
    echo "良好"
fi

测试条件详解

数值比较、字符串比较、文件测试等条件

# 数值比较
[ $num1 -eq $num2 ]  # 等于
[ $num1 -ne $num2 ]  # 不等于
[ $num1 -lt $num2 ]  # 小于
[ $num1 -gt $num2 ]  # 大于

# 字符串比较
[ "$str1" = "$str2" ]  # 相等
[ -z "$str" ]        # 字符串为空
[ -n "$str" ]        # 字符串非空

# 文件测试
[ -f "$file" ]       # 是普通文件
[ -d "$file" ]       # 是目录
[ -e "$file" ]       # 文件存在

for 循环

遍历列表、数组或范围进行重复操作

# 遍历列表
for item in apple banana orange; do
    echo "Fruit: $item"
done

# 遍历数字范围
for i in {1..5}; do
    echo "Number: $i"
done

# 遍历文件
for file in *.txt; do
    echo "Processing $file"
done

while 循环

当条件为真时持续执行循环体

# 基本 while 循环
counter=1
while [ $counter -le 5 ]; do
    echo "Count: $counter"
    counter=$((counter + 1))
done

# 读取文件内容
while read line; do
    echo "Line: $line"
done < file.txt

函数定义和调用

基本函数

# 函数定义
function greet() {
    echo "Hello, $1!"
}

# 或者简化写法
greet() {
    echo "Hello, $1!"
}

# 函数调用
greet "World"
greet "Linux"

带返回值的函数

# 计算函数
add_numbers() {
    local num1=$1
    local num2=$2
    local result=$((num1 + num2))
    echo $result
}

# 使用函数
result=$(add_numbers 10 20)
echo "Sum: $result"
